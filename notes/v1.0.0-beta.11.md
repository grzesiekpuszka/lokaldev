## New

- **Additional domains for a project** (project settings, e.g. `license.vifee.test, account.vifee.test`). They're served by the project's Apache and Nginx sites, added to the hosts file and included in the project's HTTPS certificate, so they work over HTTPS without hand-edited vhosts. A hand-written `<domain>.conf` that uses the project's certificate gets them in the certificate too.

## Fixes

- **Apache: a site whose domain falls under another site's `*.<domain>`** (e.g. `shop.blog.test` next to `blog.test`) is no longer caught by that wildcard, whatever the alphabetical order of their config files.
