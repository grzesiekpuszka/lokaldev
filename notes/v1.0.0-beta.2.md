## Improvements

- **Git already on your computer is used.** If Git for Windows (or another Git) is installed, lokaldev shows it in **Binaries** as *external* and no longer offers its own.
- **Terminal tools don't hide system ones.** lokaldev's terminal shortcuts now exist only for tools lokaldev provides, so a system-wide `git`, `python` and the like keep working when the lokaldev tools are on the PATH.
- **Dashboard shows running services only.** When nothing runs, it says so next to **Start all**.
- **phpMyAdmin and pgAdmin shortcuts** on the Dashboard and in the tray menu. phpMyAdmin is started first if it isn't running.
- **Project type follows the document root.** The type is detected from the document root and the folders above it, so WordPress in `public_html` is recognised. It is detected again when you add or import a project or change its document root.
