## Improvements

- **Global Composer packages live next to lokaldev.** With *Add tools to the user PATH* on, `COMPOSER_HOME` points to `data\composer` and its `vendor\bin` (e.g. `phpcs`) is on the PATH. Packages installed with `composer global` in the default `%APPDATA%\Composer` are installed again there the first time. A `COMPOSER_HOME` you set yourself is kept. If the PATH option is already on, this happens on the next start.
