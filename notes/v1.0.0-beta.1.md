First public beta of **lokaldev**, a portable local development environment for Windows. Every project gets its own PHP, Node.js, Python and database versions, and the whole stack lives in one folder: no installer, no Docker, no WSL.

## Highlights

- **Projects:** Laravel, Symfony, WordPress, Node.js, Python, plain PHP or an empty folder, created from a wizard or imported. Each project gets a `.test` domain with trusted local HTTPS.
- **Web servers:** Apache (80/443) and Nginx (8080/8443) can run side by side, and both serve every project.
- **Per-project versions:** PHP, Node.js (via nvm for Windows) and Python are chosen per project. In a project folder, `php`, `composer`, `mysql`, `psql`, `python` and other terminal commands use that project's versions.
- **Databases:** MySQL, MariaDB and PostgreSQL in several versions at once. Each project picks its server and port, and `.env` / `wp-config.php` are updated automatically. SQLite works for Laravel and Symfony.
- **Services:** MongoDB, Redis, Memcached, Mailpit, phpMyAdmin and pgAdmin, with the PHP extensions they need installed automatically.
- **Tools:** Git (MinGit), Composer, SQLite CLI, pnpm, Deno and Bun.
- **Database tools:** export and import single databases or everything at once, including Laragon / mysqldump `--all-databases` dumps.
- **Settings:** editable ports, one database login for all servers, time zone, the databases folder location, and which services start on launch.
- **Updates:** lokaldev checks for new releases and newer versions of installed binaries once a day and updates them in place. Your settings and data are kept.
- **Languages:** English and Polish.

## Getting started

1. Download `lokaldev-1.0.0-beta.1-win-x64.zip` and unpack it anywhere, for example `D:\lokaldev`.
2. Run `lokaldev.exe`.
3. Install PHP, a web server and a database in **Binaries**.
4. Create or import a project.

Projects go to `www\` and database data to `databases\`, both next to the exe. Binaries, configuration and logs are kept in `data\`.

## Known limitations

- Windows 10/11, 64-bit only.
- Starting a web server may ask for administrator rights once, to update the hosts file. Trusting the local certificate asks once too.
- The hosts file has no wildcards, so subdomains need their own entries.
- Memcached for Windows is only available as 1.6.8. There is no MongoDB PHP extension for PHP 7.4.
- MySQL and MariaDB use the system time zone.

This is a beta. Please report problems in the repository's Issues.
