## Improvements

- **"none" for PHP, Python and the database** in the project settings, as for Node.js. A project without PHP is served as static files, `php`/`python` in its folder say they're turned off, and its `.env` / `wp-config.php` is left alone.
- **Empty projects start with none** for PHP, Node.js, Python and the database.
- **Mailpit shortcut** on the Dashboard and in the tray menu. Mailpit is started first if it isn't running.

## Fixes

- **WordPress in `public_html` is recognised** even when the project was saved as custom PHP earlier (for example created as an empty project) or has no `wp-config.php` yet. A project marked as custom PHP now follows what its files show.
