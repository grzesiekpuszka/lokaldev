## Fixes

- **Updates install again.** Installing an update could stop at a terminal window titled `find "…"` and never finish. The update is now installed by a small background program, without any window: lokaldev closes, the files are replaced and the new version starts with the services that were running.

**Updating from 1.0.0-beta.1 or beta.2:** these versions still have the broken installer, so update them by hand once. Close lokaldev (and the terminal window, if it's still open), then unpack this release's zip over your lokaldev folder. `data`, `www` and `databases` aren't in the zip, so your settings, projects and databases stay. Later updates install from within the app.
