## Improvements

- **WP-CLI** can be installed in *Binaries → Tools*. With *Add tools to the user PATH* on, `wp` works in any terminal and runs with the PHP version of the project you're in.
- **Imagick for PHP.** *PHP → Extensions* lists `imagick` for every PHP version; turning it on downloads the official Windows build (with ImageMagick) and enables it.
