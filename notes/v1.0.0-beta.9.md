## Fixes

- **New projects use the document root you choose.** WordPress, custom PHP and empty projects created with a document root such as `public_html` now put their files (and `wp-config.php`) into that folder and create it; before, the files landed in the project folder and the site pointed to a folder that didn't exist.
- **A target folder that holds only empty folders** (e.g. a `public_html` you created beforehand) is accepted for new WordPress, custom PHP and empty projects. Laravel and Symfony still need an empty folder, as Composer requires.
- **Downloads that stall** (the connection stops sending data) fail after a minute with a clear message instead of hanging the wizard or the install forever.
